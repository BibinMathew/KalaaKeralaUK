## Review limits

The reference's embedded events content displayed an organisation-policy block in this browser. Its Office Bearers page returned HTTP 406 in web retrieval; the homepage committee preview was visible. Only the first step of the external membership form was available for read-only review. Therefore this is not a claim of complete hidden-form or calendar parity. No membership application was submitted to the reference site.

## Intentional differences

Kalaa Kerala uses its own green/gold branding and supplied logo. The reference's blue styling, photographs, people, claims and contact information are not reused. The initial homepage uses a static hero rather than an auto-advancing slider. All known public sections are represented; the calendar and Stripe checkout are native additions. We avoid fabricated event dates and club history. The optional local demo is labelled DEMO.
